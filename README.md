# Jaz Official Plugins

Official plugin marketplace for Jaz.

## Included plugins

- **Tasks** (`plugins/tasks`) — Jaz Tasks remote MCP server (`https://tasks.jaz.chat/mcp`).
- **Customer Relationship Management** (`plugins/crm`) — Jaz CRM remote MCP server (`https://crm.jaz.chat/mcp`).
- **Granola** (`plugins/granola`) — Granola meeting notes and transcripts MCP server (`https://mcp.granola.ai/mcp`).
- **Zoom** (`plugins/zoom`) — Zoom meeting recordings and transcripts MCP server (`https://mcp.zoom.us/mcp/zoom/streamable`).
- **Jaz Skills** (`plugins/jaz-skills`) — Core Jaz workflow skills.
- **Revit Viewer** (`plugins/revit-view-extract`) — Local Revit 2024 engineering extraction and saved-mesh viewing. [Source and native releases](https://github.com/cambridgeadvancedsystems/revit-view-extract).
